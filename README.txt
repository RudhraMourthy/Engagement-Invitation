ENGAGEMENT INVITATION WEBSITE

Files:
- index.html: responsive invitation website with animations, countdown, and music toggle
- invitation.png: invitation artwork
- soft-instrumental.wav: original gentle synthesized instrumental loop

Publish with GitHub Pages:
1. Create a public GitHub repository.
2. Upload all three files (index.html, invitation.png, soft-instrumental.wav) to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. After deployment, share the URL shown in Settings > Pages.

Music note:
Browsers generally block audio autoplay. Visitors can tap “Play soft music” to start the quiet instrumental; they can pause it any time. Music starts at a low volume.
